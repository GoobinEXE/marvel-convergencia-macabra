# Convergência Macabra (Hub da Campanha)

## Visão Geral
One-shot de até 5 horas nos tempos modernos para preparar o grupo para o clima de *Doutor Estranho no Multiverso da Loucura*. Calibrada para **até 5 jogadores criando heróis originais de Rank 4** (TN base *Challenging* = **14** no sistema d616).

### A Corporação: Roxxon Energy
* **Fachada Pública:** Fonte infinita de energia limpa para o planeta.
* **Objetivo Real:** Drenar a energia de [[Brie (Ser Nexus)]] até o limite para construir um **arsenal militar gigantesco**, gerando o conflito inicial ao transferir a criança entre instalações.
